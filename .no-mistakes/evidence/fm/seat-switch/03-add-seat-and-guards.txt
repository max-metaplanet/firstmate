seat profile directory: /tmp/fmseatB.2qkZ/seats/lab-a

This created an empty profile directory and nothing else. No credential
was read, copied, or written, and the Keychain was not touched.

The account owner now logs this seat in, personally, in a terminal:

  CLAUDE_CONFIG_DIR=/tmp/fmseatB.2qkZ/seats/lab-a claude

then runs /login inside that session and signs in as the account this
seat should bill to. Claude Code stores those credentials under a
Keychain entry derived from this directory path, so they never mix with
the default login. Confirm with:

  bin/fm-seat.sh probe lab-a

and then make it the active seat with:

  bin/fm-seat.sh switch lab-a
exit=0

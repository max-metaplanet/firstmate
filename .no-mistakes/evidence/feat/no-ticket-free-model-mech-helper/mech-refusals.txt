mech hands a rename, a format, boilerplate, or test scaffolding to a free OpenCode model.
  --model must be a documented free OpenCode id (last segment free, big-pickle, or ending
  -free or :free) or be omitted; any other id is refused.
  Each --path is relative to the repository top level, and the diff carries only
  changes under those paths. A --path in the ci, migrations, infra, auth, payments,
  env, or doppler class, or a secrets file or token store, is refused, and so is a
  result in which the model changed such a path, even inside a declared directory.
  The model runs confined, with tokens scrubbed, on a scratch copy of your current tree
  that leaves out refused paths. mech prints only the model's change as a diff against
  that copy and never touches your worktree; review it, then git apply it at the top level.
exit=2
